**Contributions are welcome!** You don’t need to implement a full recommendation to contribute—
even adding a small section may benefit others. The package currently includes some implementations
that are fully or nearly complete, as well as others where only a small section has been
implemented.


## How to Contribute Code

1. Fork the repository to your GitHub account.
2. Clone your fork locally and create a new branch for your feature or bugfix.
3. Make your changes and, as reasonable, ensure your code passes Pylance and Pylint checks with the
provided .pylintrc configuration.
4. Add or update tests to cover your changes when ITU validation data is available.
5. Document new or modified functions using
[Google-style docstrings](https://google.github.io/styleguide/pyguide.html#38-comments-and-docstrings).
6. Commit your changes with clear, descriptive messages.
7. Push your branch to your fork on GitHub.
8. Open a pull request against the main repository. Include a summary of your changes and reference
any relevant issues.

#### Other Considerations

Prioritize using standard Python packages (i.e., those included with the Python Standard Library)
or packages already used in the project to minimize introducing new dependencies.
